This is my first Arduino simulation project created while learning Arduino and basic electronics.

## Project Objective

To blink an LED continuously using an Arduino Uno.

The LED:
- Turns ON for 3 seconds
- Turns OFF for 3 seconds
- Repeats continuously

## Components Used

- Arduino Uno
- LED
- 220Ω Resistor
- Jumper Wires

## Circuit Connection

Arduino Pin 9 → 220Ω Resistor → LED → GND
