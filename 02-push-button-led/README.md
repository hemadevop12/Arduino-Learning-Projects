Push Button Controlled LED:
  This is an Arduino simulation where an LED is controlled using a push button.

Components used:
  1.Arduino UNO
  2.330-ohm resistor 
  3.1k ohm resistor
  4.Push Button
  5.LED
  6.Jumper wires

Working principle:
 Push Button is connected to pin 2 of Arduino
 LED is connected to pin 13 of Arduino
 When the button pressed Arduino reads the input from button based on this the LED will turn ON or OFF

Concepts Learned:
 digitalRead()
 LED Polarity
 Serial monitor debugging
 Voltage measurement using multimeter
 Pull-Down resistor

Simulation:
 The Circuit was designed and tested by tindercad circuits.
